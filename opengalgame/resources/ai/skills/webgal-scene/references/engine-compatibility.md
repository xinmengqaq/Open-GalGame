# 引擎兼容性

当前资料核对 WebGAL parser/engine 4.6.5，运行输入提供实际安装版本。参考修订 cf73dd58535d3ef15bddf0852adee153fa92d7da。当前引擎不注册 if、chooseLabel，解析器识别不等于引擎能执行。

依据：[官方语法](https://docs.openwebgal.com/webgal-script/base.html)、本项目锁定的 webgal-parser SCRIPT_CONFIG 与 webgal-engine 注册表。未知参数不得自行创造。动画预设只使用工程提供并实际存在的配置。

本技能为本项目原创（MIT），未复制第三方定制引擎教程。技能只描述语法；文件存在不代表资源可解码或演出已执行。
