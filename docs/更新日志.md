# 更新日志

## 0.3.0（2026-11-25）

### 新手指引

- 新增八步新手教程：从连接模型、新建工程、放入剧本，到编排画面与声音、生成候选、试玩改词、导出成品，直接在页面上标出你下一步该点哪里。
- 首次打开首页会收到一次教程邀请；跳过后，随时可以从页面右下角或「应用设置」重新打开。
- 教程步骤支持自由前后切换，也可以从目录直接跳步；浮窗可拖动或收起，重开应用会回到上次看的位置。

### 界面与体验

- 项目页、连接设置、新建工程和导出弹窗统一换为圆角玻璃风格；项目卡片换用按作品生成的专属场景插画。
- 工作台「输入摘要」改为按素材类型分组，缺用途说明的卡片可以一键回画布补齐；「AI 历史」与「作品历史」改为按日期排布的时间线，关键状态和回退记录更易看清。
- 清理了各页面多余的说明小字，操作直接做成可见按钮（如项目卡右上角的「…」菜单、提示词卡的编辑与 `@ 引用` 按钮）。全局通知固定在右上角，支持手动关闭。

### 修复

- 修复了桌面端启动报错无法打开的问题。
- 连接测试失败时，右上角通知会直接给出排查方向（如检查地址、端口、模型服务或扩展请求头），且不再被设置弹窗遮挡。
- 修复了项目列表里存在已删目录的旧工程时，新工程导入文件或保存画布报错「版本记录无法读取」的问题。
- 修复了空画布和异常状态下「保存」按钮仍可点击、导出后点「打开所在文件夹」无状态提示，以及中文字体显示粗细不一的问题。

### 设置

- 首页统一为单一「设置」入口，设置中心分为「外观与舒适度」「模型连接」「新手引导与更新」；顶部横向分区、单列内容，切区自动回到顶部。
- 外观新增阅读预览、语义化阅读字号、玻璃通透度、清晰高对比和减少动态效果；内置思源黑体、思源宋体、霞鹜文楷 GB、得意黑四套字体，不再要求本机安装。
- 模型连接改为统一两列字段网格，同排标签同基线、控件同高，说明独立成行；扩展请求配置整行展示，窄窗口自动收为单列。
- 保存失败、放弃草稿和引导重学确认改为副层弹窗，帮助说明改为按需浮层；不再用内嵌横幅或常驻小字挤占表单。
- 新增「关于与许可」弹窗，说明 Apache-2.0 许可、官方发行、第三方发行责任、无担保、名称与品牌以及第三方字体许可。
- 修复打开或关闭设置后首页横向滚动、丢弃确认默认焦点落在关闭按钮、保存失败后焦点丢失，以及连接读取失败文案不准确的问题。

## 0.2.0（2026-11-22）

### AI 场景创作

- 场景生成换用了 Pi Agent Core。你可以继续使用原来的模型，从画布开始创作。先试玩 AI 写出的候选，满意后再接受；未接受的内容不会写入作品。
- 想给同一场戏试两种写法？在「AI 历史」中选中可分叉的记录，点「从这里分叉」，就能保留原稿、另试一版。即使接受了新分支，仍能回到原任务继续处理。
- 创建分叉后如果提示「结果待核对」，不用再创建一次。到「AI 历史」点「重新核对」，看看分支是否已经建好。重新打开工程也不会自动让 AI 重写场景。

### 场景导出

- 接受候选后，可以直接点「导出当前场景」，不必再去预览页保存一次。游戏默认放在当前工程的 `exports` 文件夹，也可以选择其他位置。
- 导出完成后，点「打开所在文件夹」就能找到游戏。如果目标位置已有同名文件夹，但不是本应用导出的游戏，工作台不会覆盖它。

### 修复

- 修复了修改其他场景后，原本可以接受的候选也被判为失效的问题。如果改动的是候选要替换的场景脚本，工作台仍会保留你手写的内容，不会直接覆盖。
- 修复了「取消生成」和「丢弃候选」确认框背景透出、文字难以辨认的问题。

### 升级提醒

- 建议先备份工程，并在旧版处理尚未结束的生成任务。对于无法确认进度的旧任务，新版不会自动续写。

## 0.1.0（2026-11-12）

### 新增

- Windows x64 安装包：NSIS 按用户安装，默认安装到 `%LOCALAPPDATA%\Programs\opengalgame`，不需要管理员权限，不显示安装目录页；创建桌面快捷方式，保留卸载入口。
- 应用内更新：首页「应用设置」可检查更新、由用户确认后下载、下载完成后重启安装；显示检查、下载、可安装、安装中和失败状态，下载进度未知时使用不确定进度条。
- 更新失败可重试，并固定提供 GitHub Releases 手动下载入口。
- 上次更新未完成时，下次启动提示「上次更新未能完成，请重新下载或手动安装」，确认后才进行后台检查。
- 首页显示「有新版本 / 待重启」非模态提示，不打断当前操作。

### 修复

- 文档层禁止插入图片：粘贴或拖入图片被拦截，不打开文件选择器、不新增图片、不离开页面，并提示「文档不支持图片，正文保持原样」。
- 打包后打开「新建素材 → 文档」空白：修复 md-blockkit 与应用各自带入一份 React 导致的渲染异常。
- 应用图标统一为品牌图（安装包、程序、窗口与任务栏一致），不再使用纯色占位图。

### 构建与依赖

- `md-blockkit` 改为固定提交的 Git 子模块，从源码构建，不再依赖本机外部目录的预构建产物。
- 发布源为 GitHub Releases：`https://github.com/xinmengqaq/Open-GalGame`，不使用镜像或运行时自定义地址。
- `v*` 标签触发 Windows 构建并上传安装包、`latest.yml` 与差分 blockmap；标签必须与 `package.json` 版本一致。

### 已知限制

- 安装包未做代码签名。Windows SmartScreen 可能提示未知发布者，需要用户手动允许。
- 应用内检查更新依赖仓库已发布带 `latest.yml` 的 Release；仓库没有 Release 时无法获取版本信息。
