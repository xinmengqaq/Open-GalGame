# 更新日志

## 0.1.0（2026-11-12）

### 新增

- Windows x64 安装包：NSIS 按用户安装，默认安装到 `%LOCALAPPDATA%\Programs\opengalgame`，不需要管理员权限，不显示安装目录页；创建桌面快捷方式，保留卸载入口。
- 应用内更新：首页「应用设置」可检查更新、由用户确认后下载、下载完成后重启安装；显示检查、下载、可安装、安装中和失败状态，下载进度未知时使用不确定进度条。
- 更新失败可重试，并固定提供 GitHub Releases 手动下载入口。
- 上次更新未完成时，下次启动提示「上次更新未能完成，请重新下载或手动安装」，确认后才进行后台检查。
- 首页显示「有新版本 / 待重启」非模态提示，不打断当前操作。

### 修复

- 文档层禁止插入图片：粘贴或拖入图片被拦截，不打开文件选择器、不新增图片、不离开页面，并提示「文档不支持图片，正文保持原样」。
- 打包后打开「新建素材 → 文档」空白：修复 md-blockkit 与应用各自带入一份 React 导致的渲染异常。
- 应用图标统一为品牌图（安装包、程序、窗口与任务栏一致），不再使用纯色占位图。

### 构建与依赖

- `md-blockkit` 改为固定提交的 Git 子模块，从源码构建，不再依赖本机外部目录的预构建产物。
- 发布源为 GitHub Releases：`https://github.com/xinmengqaq/Open-GalGame`，不使用镜像或运行时自定义地址。
- `v*` 标签触发 Windows 构建并上传安装包、`latest.yml` 与差分 blockmap；标签必须与 `package.json` 版本一致。

### 已知限制

- 安装包未做代码签名。Windows SmartScreen 可能提示未知发布者，需要用户手动允许。
- 应用内检查更新依赖仓库已发布带 `latest.yml` 的 Release；仓库没有 Release 时无法获取版本信息。
